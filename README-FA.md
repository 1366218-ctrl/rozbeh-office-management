# برنامه مدیریت ماشین‌های اداری روزبه

## امکانات نسخهٔ اولیه
- رابط فارسی راست‌چین و واکنش‌گرا برای کامپیوتر و موبایل
- ذخیرهٔ محلی در مرورگر و استفادهٔ آفلاین پس از بارگذاری اولیه
- مدیریت مشتری، قطعات/کالاها، سفارش تعمیر، فاکتور فروش/خدمات و دخل‌وخرج
- پیش‌نمایش فاکتور، چاپ یا ذخیره به PDF از پنجره چاپ سیستم، و ساخت پیام واتساپ
- خروجی و بازیابی پشتیبان JSON
- اتصال ابری اختیاری با Supabase Auth + جدول دارای RLS برای همگام‌سازی بین دستگاه‌ها

## بارگذاری روی میزبانی استاتیک
تمام فایل‌های پوشه را در ریشهٔ سایت بارگذاری کنید. نیازی به build ندارد. برای نصب روی موبایل، سایت باید از HTTPS ارائه شود؛ سپس در مرورگر گزینهٔ Add to Home Screen / افزودن به صفحهٔ اصلی را انتخاب کنید.

## راه‌اندازی همگام‌سازی ابری (اختیاری)
1. در Supabase یک پروژه بسازید.
2. در SQL Editor محتوای `supabase-schema.sql` را اجرا کنید.
3. در Authentication تنظیم کنید که حساب فقط در اختیار مالک باشد؛ در صورت نیاز تأیید ایمیل را انجام دهید.
4. در برنامه > پشتیبان و تنظیمات، Project URL و کلید عمومی (anon/publishable) را وارد و ذخیره کنید. هرگز service_role key را وارد نکنید.
5. ورود را انجام دهید و سپس «همگام‌سازی» را بزنید.
6. روی دستگاه دوم همان سایت را باز کنید، با همان حساب وارد شوید و همگام‌سازی را اجرا کنید.

## محدودیت‌های مهم
- همگام‌سازی ابری تا زمانی که پروژه Supabase ساخته و schema اجرا نشده باشد فعال نیست. فایل سایت به‌تنهایی سرویس ابری ندارد.
- در نسخهٔ اولیه، همگام‌سازی از نوع ادغام بر اساس آخرین زمان ویرایش هر رکورد است؛ تغییر هم‌زمان یک رکورد در دو دستگاه نیازمند بررسی دستی است. برای داده‌های حیاتی، قبل از همگام‌سازی در هر دو دستگاه پشتیبان بگیرید.
- حذف رکوردها در این نسخه به‌صورت حذف محلی است و هنوز tombstone همگام‌سازی‌شده ندارد؛ برای همین حذف را هم‌زمان روی چند دستگاه انجام ندهید.
- ارقام به‌صورت عدد ذخیره می‌شوند و واحد نمایشی «تومان» است؛ این نسخه دفترکل رسمی یا نرم‌افزار مالیاتی نیست.
- چاپ به PDF با گزینهٔ Print / Save as PDF مرورگر انجام می‌شود. ارسال واتساپ متن فاکتور را باز می‌کند؛ PDF باید جداگانه ذخیره و در واتساپ پیوست شود.
- برنامه فعلاً ابزار مدیریت سبک است، نه جایگزین نرم‌افزار حسابداری رسمی یا مشاوره مالیاتی.

## چک‌لیست پیش از استفادهٔ واقعی
- پشتیبان بگیرید و بازیابی آن را آزمایش کنید.
- یک مشتری، کالا، تعمیر، فاکتور با مانده، و هزینهٔ آزمایشی ثبت کنید.
- چاپ و PDF را روی دستگاه خود بررسی کنید.
- اگر Supabase را فعال می‌کنید، ابتدا با دادهٔ آزمایشی همگام‌سازی را در دو دستگاه آزمایش کنید.
